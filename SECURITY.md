# Security policy

This policy covers the ViralGenHub service at app.viralgenhub.com and viralgenhub.com, and the code in this repository.

## Reporting a problem

Email **support@viralgenhub.com** with "Security" in the subject. Please include:

- what the problem is and what it could let someone do;
- the steps to reproduce it;
- a proof of concept, if you have one.

Please don't open a public GitHub issue for security problems, and don't test against other users' accounts or data. We will acknowledge your report, keep you updated, and not disclose it publicly until it is fixed.

## Problems in Postiz itself

ViralGenHub is built on [Postiz](https://github.com/gitroomhq/postiz-app). If the problem is also in upstream Postiz, please report it to them as well, through the process in [their security policy](https://github.com/gitroomhq/postiz-app/blob/main/SECURITY.md).
